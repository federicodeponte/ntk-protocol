# Code of Conduct

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique ideas and not people, and no harassment of any kind. Maintainers may remove comments, commits or contributors that break these rules.

Report problems privately to the maintainer through GitHub (see [SECURITY.md](SECURITY.md) for the private reporting link). Reports are handled confidentially.
